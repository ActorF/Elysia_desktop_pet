# 爱莉希雅桌宠 1.1.0 · 更新说明

新增按键云朵：输入字符时，爱莉希雅会用云朵显示最近按下的一个字符。

- 支持数字、大小写英文字母、标点与空格；空格显示为 `␣`。
- 待机、吃蛋糕和喝奶茶时，浅粉白色圆云朵显示在手心上方，约一秒内消失。
- 喇叭动作时，云朵从喇叭口边缘向左上飘出，带扩音弧线，一秒内逐渐淡出。特效仅为图像，不播放声音。
- 可在系统托盘开关按键云朵。输入只用于即时显示，不记录或保存按键历史。
- 为外飘特效保留透明空间，透明空白支持点击穿透。

## English

Version 1.1.0 adds key clouds that display the most recently typed character.

- Supports digits, uppercase and lowercase English letters, punctuation, and spaces. Spaces appear as `␣`.
- While idle, eating cake, or drinking milk tea, a pale pink cloud appears above the palm and disappears in about a second.
- During the megaphone action, clouds drift toward the upper left with sound-wave arcs and fade within a second. The effect is visual only.
- Key clouds can be toggled from the tray. Input is used only for the immediate effect; no key history is recorded or saved.
- Extra transparent space accommodates the drifting effect while allowing clicks to pass through empty areas.
