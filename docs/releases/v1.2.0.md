# 爱莉希雅桌宠 1.2.0 · 更新说明

[下载 Windows 便携版 1.2.0](https://github.com/ActorF/Elysia_desktop_pet/releases/download/v1.2.0/Elysia_desktop_pet-1.2.0.exe) · [SHA256 校验文件](https://github.com/ActorF/Elysia_desktop_pet/releases/download/v1.2.0/Elysia_desktop_pet-1.2.0.exe.sha256)

这一版让设置更方便，也能按你的喜好调整桌宠的摆动、目光跟随和任务栏前后顺序。

## 新增与调整

- **独立设置窗口。** 托盘菜单简化为“设置”和“退出”。设置窗口与人物同时存在，可以单独移动、调整大小、最小化和最大化；关闭设置窗口后，桌宠继续运行。
- **设置界面重新设计。** 圆角与浅粉紫渐变，按“外观／动画／桌面”组织功能。顶部保留最小化、最大化／还原、关闭三个图标。
- **摆动幅度与速度可调。** 幅度支持 0–200%，速度支持 0.25–3×；可用滑块或数值框调整，也能分别恢复默认值。
- **眼睛跟随幅度可调。** 保留原来的眼睛跟随效果，强度支持 0–200%，默认 100%。
- **任务栏层级可选。** 开启“始终置顶”后，可以选择任务栏在前或桌宠在前。
- **更新托盘图标。** 使用透明背景的粉色图案，裁去多余留白，让图标在托盘中更清楚。

设置自动保存。升级继续使用原来的用户设置目录，保留位置、大小和装扮开关。11 种脸部状态、猫猫与眼镜组合、四种动作、按键云朵、自由拖动和右键加滚轮缩放继续可用。

## 运行与下载

下载 `Elysia_desktop_pet-1.2.0.exe`，双击即可运行，无需安装 Node.js。升级前从右下角托盘退出旧版，再打开新版；已有位置、大小、装扮和设置会保留。

点击托盘图标，选择“设置”即可打开独立窗口。完整操作说明、设置截图和[源码运行方式](../../README.md#源码运行)见 [README](../../README.md)。
