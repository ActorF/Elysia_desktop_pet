# 爱莉希雅桌宠 1.2.0 · 更新说明

1.2.0 已合并至 `main`，可从主分支运行或自行打包。GitHub Releases 尚未发布 1.2.0 便携版；当前可下载的 EXE 仍为 [1.1.0](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.1.0)。

## 新增与调整

- **独立设置窗口。** 托盘菜单简化为“设置”和“退出”。设置窗口与人物同时存在，可以单独移动、调整大小、最小化和最大化；关闭设置窗口后，桌宠继续运行。
- **设置界面重新设计。** 圆角与浅粉紫渐变，按“外观／动画／桌面”组织功能。顶部保留最小化、最大化／还原、关闭三个图标。
- **摆动幅度与速度可调。** 幅度支持 0–200%，速度支持 0.25–3×；可用滑块或数值框调整，也能分别恢复默认值。
- **眼睛跟随幅度可调。** 保留原来的眼睛跟随效果，强度支持 0–200%，默认 100%。
- **任务栏层级可选。** 开启“始终置顶”后，可以选择任务栏在前或桌宠在前。
- **更新托盘图标。** 使用透明背景的粉色图案，裁去多余留白，让图标在托盘中更清楚。

设置自动保存。升级继续使用原来的用户设置目录，保留位置、大小和装扮开关。11 种脸部状态、猫猫与眼镜组合、四种动作、按键云朵、自由拖动和右键加滚轮缩放继续可用。

## 运行与下载

按 [README 的源码运行说明](../../README.md#源码运行)从 `main` 启动 1.2.0。设置窗口预览与完整操作说明也在 README 中。

本地构建的便携版无需安装 Node.js；运行前从托盘退出旧版。EXE 不提交到源码仓库，1.2.0 的公开安装包发布将另行进行。

## English

**Version 1.2.0 has been merged into `main`** and can be run or packaged from source. A 1.2.0 portable EXE has not yet been published on GitHub Releases; the available download remains [1.1.0](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.1.0).

- A separate, movable and resizable settings window. The tray menu now contains only Settings and Quit. Closing Settings keeps the pet running.
- A rounded interface with a soft pink/lavender gradient and Appearance, Animation, and Desktop tabs. Standard minimize, maximize/restore, and close icons remain at the top.
- Adjustable sway amplitude (0–200%) and speed (0.25–3×), with sliders, number fields, and individual reset buttons.
- Adjustable eye-follow strength (0–200%), retaining the original effect at the default 100%.
- A choice between taskbar in front and pet in front when Always on top is enabled.
- A transparent pink tray emblem with excess padding removed.

Existing preferences remain compatible. Expressions, outfit switches, actions, key clouds, free dragging, and right-button wheel resizing remain available. The settings interface currently uses Chinese labels.

See [Run from source](../../README.en.md#run-from-source) to run 1.2.0 from `main`. Executables are not committed to the source repository; publication of the 1.2.0 portable EXE will be handled separately.

Validation passed: 133 unit tests, 18 settings UI checks, 11 zoom checks, hidden startup checks for both packaged forms, and exact packaged file/source verification.
