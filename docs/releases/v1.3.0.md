# 爱莉希雅桌宠 1.3.0 · 更新说明

1.3.0 加入日常语音、点击回应和鼠标流光，让桌面陪伴可以按自己的习惯调整。继续使用原有角色素材，保留表情、装扮、动作、按键云朵、拖动与缩放功能。

本仓库提供 1.3.0 源码及本地构建方式，尚未发布 1.3.0 下载附件。当前公开的便携版下载仍为 [1.2.0](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.2.0)。

## 新增与调整

- **36 句日常语音。** 12 类场景各有三句，按照本地时间、活跃状态和使用记录轮换播放，包括早晚问候、饭点、休息、欢迎回来、生日和告别。
- **18 句点击互动语音。** 轻点头部摸摸头，轻点身体戳一戳；两处点击一起计数，3 秒内第 5 次点击触发生气回应。三类互动各有六句。
- **完整台词气泡。** 粉色边框、白色背景，只显示台词，按长度调整大小，最多两行。角色在屏幕右半边时气泡在左，在左半边时气泡在右，跟随拖动和缩放。
- **语音防冲突。** 快速点击合并回应，当前语音不会被普通点击打断，等待中的生气回应最多一条。日常问候和互动共用播放控制，录音不会叠加。
- **独立互动设置。** 设置增加“互动”和“语音”页；点击互动、鼠标流光、自动日常问候分别控制，提供勿扰、音量和生日月日设置。正式界面移除试听、模拟触发及样本专用入口。
- **三种鼠标流光。** 细粉色流光、紫色粗头到玫粉细尾的绸光、星尘尾迹。覆盖层不挡点击、不抢焦点，支持快速甩动、画圈和多显示器。
- **轨迹保留时间可调。** 支持输入 0.1–5 秒的小数，默认 0.6 秒；也可使用步长为 0.1 秒的滑条。长时轨迹使用有上限的历史采样保存，近期移动仍保留细节。
- **修复首次快速移动丢失。** 没有实际几何变化的显示器通知不再清空待显示轨迹，流光窗口不再转发不需要的鼠标移动事件。

## 点击与语音的使用方式

从托盘打开“设置 → 互动”，开启“点击互动”。左键轻点头顶或刘海是摸头，轻点其余人物区域是戳戳；拖动与右键滚轮缩放不计为点击。触发生气后有 3 秒冷却，临时互动表情会恢复为原表情。

互动语音各组轮换，避免相邻重复。约 0.3 秒内的连续点击会合并；达到五次时以生气回应为准。已经开始的录音继续播完，普通后续点击不排队。生气回应最多等待一条，需在 6 秒内轮到播放，两句有声音频之间保留约 1.2 秒间隔。

“点击互动”和“自动触发语音”互相独立。关闭点击互动会立即停止当前互动声音、字幕和待播回应，仍可拖动、缩放和接收日常问候。勿扰或音量为 0 时，点击仍显示表情与文字。锁屏、休眠或全屏时暂停发声，恢复后不会补播旧互动。

气泡只显示完整台词，没有姓名栏或额外关闭按钮。正常录音结束后字幕约再停留 1.2 秒；文字回应按句长停留后自动消失。气泡会限制在所在显示器可用范围内，极端放大时优先保证字幕可见。

托盘“退出”可能先播放告别，再次选择退出可立即跳过。正在说话、刚结束不足 10 秒或处于勿扰、静音、全屏等状态时直接退出。关闭设置窗口和系统关机不追加告别。

## 日常语音的触发条件

每类三句共享条件，一次只播一句。“活跃”指最近 60 秒内有键鼠操作；启动至少 5 秒后开始判断。时间使用电脑的本地时区，时段包含开始、不包含结束。

| 场景 | 条件 |
| --- | --- |
| 早上好 | 06:00–10:00 首次活跃，每天一次。 |
| 晚上好 | 18:00–22:00 首次活跃，每天一次；周五由周五问候替代。 |
| 还不睡 | 00:00–03:00 内连续使用电脑满 10 分钟，每个凌晨一次。 |
| 吃了没 | 午饭 11:30–13:00、晚饭 17:30–19:00，各饭点首次活跃时一次。 |
| 欢迎回来 | 桌宠运行期间离开或锁屏至少 30 分钟，回来后等待 5 秒，每天最多两次。 |
| 休息一下 | 连续使用满 60 分钟，期间没有至少 5 分钟的休息；每阶段一次、每天最多两次。 |
| 午后问候 | 14:00–16:00 首次活跃，每天一次。 |
| 周五晚上 | 周五 18:00–23:00 首次活跃，每周一次，并完成当天普通晚上问候名额。 |
| 周末问候 | 周六或周日 10:00–18:00 首次活跃，每天一次。 |
| 好久不见 | 有历史记录，距离上次实际活跃至少 72 小时，回来后等待 5 秒。 |
| 生日祝福 | 保存生日月日后，当天首次活跃，每年一次；第三句需要往年的祝福记录。2 月 29 日只在闰年当天触发。 |
| 暂时告别 | 主动从托盘退出，且符合可发声条件时播放。 |

自动问候至少间隔 20 分钟，每天最多 6 次；生日与告别不占这 6 次，生日仍遵守问候冷却。同时符合多个条件时只选择优先级最高的一句，其余不排队补播。锁屏、休眠、全屏、勿扰、静音或监测尚未就绪时暂停自动问候。播放次数与冷却在本机保存，实际开始播放才计入。

活跃判断使用系统空闲时长与锁屏等状态，不读取输入内容。生日只保存月日。按键云朵仍由自己的开关控制，输入仅用于即时显示。

## 流光设置

“设置 → 互动”中的“鼠标流光”与“点击互动”分别保存，默认均开启。流光样式默认是“粉色流光”，还可选择“紫粉绸光”或“星尘尾迹”。紫粉绸光的颜色沿实际移动路径渐变，前端较粗、尾端较细。

在“轨迹保留时间”中输入 `0.6`、`1.3`、`2.5` 等秒数，按 Tab、Enter 或点击其他位置完成输入；允许范围为 0.1–5 秒，“默认”恢复 0.6 秒。关闭流光时也能预设样式和时长，重新开启后使用。修改样式、时长或关闭流光会立即清除旧轨迹。

跨显示器、锁屏或休眠恢复后从新位置重新开始，不连接到旧轨迹。鼠标停止后按所设时长淡出，清空后停止绘制。

## 配置与构建

正式配置位于 `%APPDATA%/Elysia Desktop Pet/`，保留已有位置和偏好。若此前使用本地 1.3 样本，仅在正式配置缺失时迁入新增选项与语音历史，不覆盖已有设置。

在 Windows 安装 Node.js 22 或更新版本后，于仓库目录执行：

```powershell
npm ci
npm start
```

构建便携版并核对内容：

```powershell
npm run make:portable
node scripts/verify-package.cjs
```

生成文件为 `release/Elysia_desktop_pet-1.3.0.exe`。录音分别位于 `assets/voice/` 与 `assets/interaction-voice/`，随构建复制，并按清单核对完整性。相关权利说明见 [ASSET-NOTICE.md](../../ASSET-NOTICE.md)。

## English

Version 1.3.0 adds 36 daily voice lines across 12 situations and 18 click responses across head pats, pokes, and annoyed reactions. Head and body clicks share a counter: five clicks within three seconds trigger an annoyed response. Recordings share playback control and do not overlap.

Complete captions appear in white speech bubbles with pink borders, with at most two lines. The bubble selects the opposite side of the character based on her position in the current display and follows dragging and resizing.

The settings window now has Interaction and Voice tabs, with independent click-interaction, cursor-trail, and automatic-greeting controls. Do not disturb, volume, and locally stored birthday month/day are available. Sample audition and simulated-trigger tools are removed from the release UI.

Three cursor styles are available: Pink glow, Purple-pink ribbon, and Stardust. Trail duration accepts decimal values from 0.1 to 5 seconds, defaulting to 0.6 seconds. Style and duration can be chosen while the trail is off. Changing either clears the old trail; the overlay remains click-through and does not take focus.

Existing release settings are preserved in `%APPDATA%/Elysia Desktop Pet/`. Missing new settings and voice history can be imported from a previous local 1.3 sample without overwriting existing values.

No 1.3.0 download attachment has been published. The latest published portable download remains [1.2.0](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.2.0). Build 1.3.0 from source using `npm ci` and `npm run make:portable`, then run `node scripts/verify-package.cjs`. Full usage is documented in [README.en.md](../../README.en.md).
