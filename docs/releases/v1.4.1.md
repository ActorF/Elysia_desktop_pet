# 爱莉希雅桌宠 1.4.1 · 历史更新说明

1.4.1 为历史测试版本，已由 1.4.2 正式版替代。旧安装版、便携版与校验文件已移除，历史源码保留；1.4.1 未创建 GitHub Release。

[下载当前 1.4.2 正式版](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.4.2) · [1.4.2 更新说明](v1.4.2.md)

## 新增与修复

- **本地聊天：** 新增独立聊天窗口，支持流式回答、停止生成、新建对话、消息复制和自定义用户名。关闭聊天窗口后桌宠继续运行；本版本使用 Ollama 与默认 Qwen 模型，人设保存在 [electron/chat-persona.md](../../electron/chat-persona.md)。
- **聊天记录管理：** 新增会话列表与消息详情，可继续对话、删除单段或清空记录，删除前确认；历史消息保留发送时的用户名。
- **可选回复朗读：** 自动朗读默认关闭，单条手动朗读不改变开关；支持复用已加载的语音模型和缓存音频，并根据正文选择语气。
- **朗读与录音协调：** 朗读遵守音量和勿扰设置，期间暂停日常与点击录音，点击仍可显示表情与文字。发送新消息、停止或关闭聊天会中止当前朗读。
- **首次自动配置：** 首次运行自动准备 Ollama、默认聊天模型与语音环境，分别显示进度、就绪状态并支持失败重试；已有自定义连接保留，准备资源不会自动开启朗读。
- **身体部位互动：** 区分头部、脸部、手部、身体、腿部和道具，回应随部位变化，点击范围跟随动作、摆动和缩放；透明间隙与装饰不触发角色点击。
- **互动表情衔接：** 普通表情短暂保持，连续点击不反复切换；各部位共用计数，3 秒内第 5 次点击优先触发生气。结束后恢复原表情，手动选择的新表情优先保留。
- **置顶修复：** 修复“始终置顶＋任务栏在前”时桌宠落到普通程序后方，以及被其他置顶应用遮挡后未恢复顺序的问题，保持“任务栏 → 桌宠 → 普通应用”的层级，同时保留输入焦点与字幕、流光的相对位置。

## English summary

Version 1.4.1 is a historical test version superseded by the stable 1.4.2 release. Its installer, portable app, and checksums have been removed; historical source remains available. No GitHub Release was created for 1.4.1.

[Download the current 1.4.2 release](https://github.com/ActorF/Elysia_desktop_pet/releases/tag/v1.4.2) · [1.4.2 release notes](v1.4.2.md)

- **Local chat:** a separate window adds streaming replies, generation cancellation, new conversations, message copying, and a customizable username. Closing chat leaves the pet running. This version uses Ollama with the default Qwen model; the persona is in [electron/chat-persona.md](../../electron/chat-persona.md).
- **Conversation history:** a conversation list and message view support continuing chats, deleting one conversation, or clearing history after confirmation. Messages retain the username used when sent.
- **Optional read-aloud:** automatic reading defaults off, and manually reading one reply does not change that setting. Loaded speech models and cached audio can be reused, with tone selected from the text.
- **Coordinated speech:** reading follows volume and Do not disturb settings and pauses daily and click recordings; clicks can still show expressions and text. Sending a new message, stopping, or closing chat cancels the current reading.
- **Automatic first-run setup:** prepares Ollama, the default chat model, and speech resources with separate progress, readiness, and retry controls. Existing custom connections are preserved; preparing resources does not enable automatic reading.
- **Body-region interactions:** head, face, hands, body, legs, and props receive distinct responses. Click regions follow actions, motion, and scale; transparent gaps and decorations do not trigger character interactions.
- **Expression transitions:** ordinary reactions briefly hold without repeated rerolls. All body regions share a counter; the fifth click within three seconds takes priority with an annoyed reaction. The previous expression returns afterward, while a newly selected expression takes precedence.
- **Always-on-top fixes:** corrects the pet falling behind ordinary apps with Always on top and Taskbar in front enabled, and restores ordering after another topmost app covers it. The taskbar → pet → ordinary apps order preserves input focus and the relative positions of caption and cursor-trail windows.
