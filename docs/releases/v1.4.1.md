## 置顶修复

在 Windows 上，副屏任务栏有时仍带有“置顶”标志，实际却排在普通程序后方。此前桌宠只要被放到这个任务栏后面，也会一起落到普通窗口后方；其他独立置顶程序覆盖后，原有维护逻辑也可能未能恢复正确顺序。

1.4.1 检查实际窗口顺序，在“始终置顶＋任务栏在前”时恢复 **任务栏 → 桌宠 → 普通应用** 的前后关系，并处理外部置顶应用造成的遮挡。修复仅校正当前可见且已置顶的真实 Windows Shell 任务栏与自有窗口的 Z 顺序，保持任务栏位置、尺寸、可见性和当前输入焦点。不会强行显示隐藏任务栏或提升被系统取消置顶的任务栏。

保留字幕、流光等辅助窗的前后顺序，并在关闭置顶或切换模式后恢复当前设置。已有聊天、设置和语音功能继续沿用 1.4.0 行为。

适用范围是普通 Windows 桌面，不承诺覆盖安全桌面、独占全屏或特殊系统层。

## 构建与检查

源码使用 `version-control` 分支；克隆时安装 Git LFS，并执行 `git lfs install`、`git lfs pull`，才能取得完整 EXE。仅下载程序无需 Git。自行构建需要 Windows、Node.js 22 或更新版本，以及忽略目录 `build-resources/voice-bootstrap/` 中的必要语音资源；浏览器回归使用 Microsoft Edge。

```powershell
npm ci
npm test
node scripts/taskbar-layer-check.cjs
npm run test:smoke
npm run test:chat-native
npm run make:release
npm run verify:release
npm run verify:setup
```

`make:release` 生成 `release/Elysia_desktop_pet-1.4.1.exe` 和 `release/Elysia_desktop_pet-1.4.1-setup.exe`；也可分别使用 `make:portable` 和 `make:setup`。构建命令不自动推送分支或发布 GitHub Release。包验证报告保存在 `artifacts/validation-v1.4.1/`，真实窗口排序脚本默认报告为 `artifacts/taskbar-layer-check.json`。完整检查方式见[验证说明](../verification.md)。

## English summary

Version 1.4.1 fixes the pet falling behind ordinary apps when Always on top and Taskbar in front are enabled. A secondary taskbar could retain its topmost flag while sitting below ordinary applications, causing the pet to be placed behind them as well. Recovery after another topmost app covered the pet is also fixed.

The fix checks actual window order and restores **taskbars → pet → ordinary apps**, correcting only visible, already-topmost Windows Shell taskbars and the app's own windows. Taskbar geometry, visibility, and keyboard focus are preserved. Caption and cursor-trail windows retain their relative order, and disabling always-on-top or switching modes restores the current setting. This does not promise precedence over the secure desktop, exclusive fullscreen, or special system layers.

Source, both EXEs, and checksums are synchronized on `version-control`; the `main` branch and GitHub Release remain unchanged. Use the [downloads above](#下载与升级) without installing Git. Cloning complete EXEs requires Git LFS. Existing settings, chat history, and prepared models are retained. The 1.4.0 chat, speech, setup, and interaction features are unchanged.

### Verification and limits

All **394 unit tests**, **196 native Windows layering checks against the packaged code**, and **nine package checks** passed. The old implementation reproduced the occlusion failure; the fixed implementation restored the expected ordering in the same scenario. The user also tested 1.4.1 and confirmed that the original always-on-top issue was fixed.

Windows checks cover real primary and secondary taskbar ordering, competition from an independent topmost process, simultaneous auxiliary windows, recovery of a removed native topmost flag, mode changes, visibility, geometry, and focus. Package checks exercise the directory app and portable EXE, and compare the installer's program files and resources; final results are recorded in the validation reports. A complete first installation of all large model dependencies on a fresh Windows machine or VM has not yet been tested.
