# 爱莉希雅桌宠 1.4.2 · 更新说明

1.4.2 改进本地聊天与回复朗读，保留原有桌宠外观、日常语音、点击互动和鼠标流光。

## 更新内容

- **聊天后台改为 llama.cpp。** 桌宠自动准备并管理本地聊天服务，无需安装 Ollama；退出时释放所属进程，再次启动复用已有模型。
- **修复手动朗读误拦截。** 自动朗读关闭时可正常朗读单条回复，普通全屏或 Windows 忙碌状态不再误取消手动请求，失败时显示具体原因。
- **改善连续朗读。** 相邻请求复用已加载的语音模型，修复朗读完成后工作进程被提前释放、下一条回复重复加载的问题。
- **恢复长消息上下文容量。** 上下文恢复为 16384 token，保留完整人设，修复部分长消息无法生成回复的问题。
- **自动补齐聊天运行库。** 自动准备程序所需的 Visual C++ 文件，已有资源也会检查与修复，聊天配置无需等待语音环境下载完成。
- **保留已有配置。** 旧版默认聊天连接自动迁移，用户名、聊天记录、装扮与个人偏好继续保留。

## English

- Replaces the default Ollama backend with app-managed llama.cpp, with automatic resource preparation, process cleanup, and model reuse.
- Fixes manual read-aloud with automatic reading disabled and prevents ordinary fullscreen or Windows busy-state detection from cancelling an explicit request.
- Reuses the loaded speech model between nearby requests instead of releasing the worker immediately after a reply.
- Restores the 16384-token chat context and fixes failures on some long messages while retaining the full persona.
- Prepares and repairs application-local Visual C++ libraries independently of speech setup.
- Migrates old default chat connections while preserving usernames, history, appearance, and preferences.
