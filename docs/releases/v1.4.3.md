# 爱莉希雅桌宠 1.4.3 · 更新说明

## 更新内容

- 聊天模型和语音环境优先从魔搭 ModelScope 国内源下载，无需注册账号或手动配置代理；连接失败时自动切换备用来源。
- 安装版和便携版附带 llama.cpp 聊天运行环境，无需首次启动时另外下载。
- 语音环境支持断点续传，取消或网络中断后重试可继续使用已下载部分。
- 修复语音下载失败被误报为资源尚未发布，以及重新下载时进度仍显示正在校验的问题。
- 自动清理语音下载缓存中的损坏包，避免重新下载后留下额外副本。

## English

- Downloads chat models and the speech runtime from ModelScope first, without an account or manual proxy setup, and automatically tries a fallback source when a connection fails.
- Bundles the llama.cpp runtime with both the installer and portable app.
- Resumes interrupted or cancelled speech runtime downloads when retried.
- Corrects misleading unpublished-resource errors and stale progress messages during speech downloads.
- Replaces damaged speech download caches without retaining an extra archive copy.
