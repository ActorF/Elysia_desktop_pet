# 爱莉希雅桌宠 1.4.5 · 更新说明

## 更新内容

- 新增屏幕底部居中的透明快捷输入框，默认使用 Ctrl + Alt + E 打开，可在设置中更换并保存全局快捷键。
- 快捷输入发送后保持显示，支持 Esc、同一快捷键或收起按钮隐藏并保留草稿；回复直接出现在爱莉希雅身旁的气泡中，无需打开聊天记录。
- 快捷输入接入已有本地回复朗读，显示语音准备、生成、播放和受阻原因，并可停止回答或朗读。
- 细分聊天与语音资源的下载、校验、解压、安装记录、文件缺失、磁盘空间及服务启动错误，新增错误编号、处理建议和复制错误信息入口。
- 新增“修复语音环境”，优先复用已下载并通过校验的资源包，准备完整环境后再切换，旧目录保留为备份。
- 改进聊天与语音环境的目录切换和中断恢复，保留失败过程中的资源；语音下载、解压前检查磁盘空间，避免普通安装覆盖过程中出现的其他目录。
- 修复重新检测时掩盖上次配置失败原因的问题，并避免语音环境配置期间重新启动朗读进程占用资源。

## English

- Adds a transparent quick input box centered at the bottom of the display, with Ctrl + Alt + E as its default and a customizable global shortcut in Settings.
- Keeps quick input open after sending. Esc, the same shortcut, or Hide tucks it away while retaining drafts; replies appear in bubbles beside Elysia without opening conversation history.
- Connects quick input to existing local read-aloud, showing speech preparation, synthesis, playback, and blocked states, with controls to stop a reply or reading.
- Adds specific chat and speech setup errors for downloads, integrity checks, extraction, installation records, missing files, disk space, and service startup, with error codes, suggested actions, and a copyable diagnosis.
- Adds voice environment repair that reuses verified downloaded archives, prepares a complete replacement before switching, and retains the old directory as a backup.
- Improves chat and speech directory switching and interrupted setup recovery, preserves resources on failure, checks space before voice resource downloads and extraction, and prevents ordinary installation from replacing a directory that appeared during setup.
- Keeps the last setup failure visible when rechecking unchanged resources and prevents read-aloud from restarting against resources being configured.
