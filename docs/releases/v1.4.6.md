# 爱莉希雅桌宠 1.4.6 · 更新说明

## 更新内容

- 修复语音资源中含 `#` 的合法文件名被误判、下载完成后无法解压的问题，并改善 Windows 目录临时占用时的处理。
- 修复朗读反复创建新盘符的问题，优先使用已有真实盘符；改善语音停止、环境修复与退出时的进程和临时资源释放。
- 改进不同地区下载来源的切换、断点续传与缓存复用。聊天模型完整但安装记录缺失或过旧时，可直接补全记录，无需重新下载模型。
- 改进聊天与语音环境修复的中断恢复、磁盘空间判断和取消操作，保留原有资源与备份，避免覆盖途中出现的其他文件。
- 语音准备过程可查看并停止，新回复与手动朗读复用已有预热；修复旧播放状态干扰新朗读、无效操作打断当前语音的问题。
- 改进快捷键编辑、不同键盘布局与冲突提示；修复反复更换快捷键后旧操作误触发、发送结果覆盖新草稿、恢复后仍显示旧错误的问题。
- 改进设置保存失败提示，保留当前调整与未保存输入；修复生日编辑和恢复默认被旧状态覆盖的问题，并保留无法读取的原配置文件。
- 改进流式聊天兼容性、多语言记录与表情符号标题处理；修复清空聊天记录后残留旧消息的问题，保护损坏的历史文件并明确提示保存失败。
- 修复设置、聊天和快捷输入窗口异常后无法重新打开的问题；“找回桌宠”可恢复异常画面并保留当前表情、动作与装扮。
- 修复系统时间调整后目光跟随、互动间隔和语音等待异常的问题，改善睡眠唤醒、全屏检测、鼠标流光和按键效果的恢复。
- 改进关闭窗口与退出时的音频清理和设置保存，避免重复后台监听；修复取消 Windows 关机后聊天或朗读不可用，以及退出时不必要的等待。

## English

- Fixes speech archives failing to extract because valid filenames containing `#` were rejected, and improves handling of temporarily busy Windows directories.
- Fixes read-aloud repeatedly creating new drive letters by reusing existing physical drives, and improves process and temporary resource cleanup when stopping speech, repairing its environment, or quitting.
- Improves download source fallback across regions, resume support, and cache reuse. An intact chat model with a missing or outdated installation record can rebuild that record without another model download.
- Improves interrupted chat and speech repair recovery, disk space checks, and cancellation while preserving original resources, backups, and files that appear during setup.
- Makes speech preparation visible and stoppable, reuses ongoing warmup for new replies and manual reading, and prevents stale playback updates or invalid actions from interrupting current speech.
- Improves shortcut editing, keyboard layout support, and conflict messages. Fixes old shortcut actions firing after repeated changes, delayed send results overwriting newer drafts, and old errors remaining after recovery.
- Makes failed settings saves visible while retaining current changes and unsaved input. Fixes older updates overwriting birthday edits or restored defaults, and preserves unreadable configuration files.
- Improves streaming chat compatibility, multilingual history, and emoji in conversation titles. Fixes stale messages remaining after history is cleared, protects damaged history files, and clarifies save failures.
- Allows Settings, Chat, and Quick input to reopen after a window failure. Bring back restores a failed pet display while retaining its expression, action, and outfits.
- Fixes eye tracking, interaction timing, and speech waits after system clock changes, and improves recovery for sleep and wake, fullscreen detection, cursor trails, and keyboard effects.
- Improves audio cleanup and settings saves when closing windows or quitting, prevents duplicate background listeners, and fixes chat or speech becoming unavailable after a cancelled Windows shutdown and unnecessary waits when quitting.
